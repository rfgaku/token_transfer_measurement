# 入金承認投票の時刻列（36件）

`analysis_votes.py` の出力。全数値は `results_votes.json`、送金ごとの値は `per_deposit_votes.csv` にある。

## 定義
- t0 = ローカル送信時刻、t1 = Arbitrum ブロックの時刻、t3 = Hyperliquid の着金時刻（hl_ledger_time）
- 有効票 = `tx_error` が空の VoteEthDepositAction。同じブロック内の順序はブロック内の取引順に従う
- A = 最初の有効票 − t1、B = 3票目の有効票 − 最初の有効票、C = t3 − 3票目の有効票、L = t3 − t0
- 4票目の遅れ = 拒否された票の時刻 − t3（着金ブロック内の場合は 0）

### 照合値との差の説明
- 分散比 A/L：36件では 1.023、exp 77 を除く35件では 0.993。照合値「≈1.00」は、35件の値（0.99）とは小数第2位の丸めで一致する。36件の値は 1.02 で、0.005 の許容幅を外れる。A/L が 1 を少し超えるのは、t1−t0 が A と弱く負に相関し（r = -0.29）、L の分散を少し打ち消しているため。t1 は秒単位に切り捨てられたブロック時刻なので、t1−t0 は平均で負になる。論文に載せる場合は「≈1（36件で1.02、35件で0.99）」と書けば両方を満たす。
- 一様＋正規：σ に下限を置かない場合の最尤推定は σ→0 の境界解（純一様、開始 3.38 s、幅 12.67 s、対数尤度 -88.9）になり、照合値とは一致しない。照合値（開始3.57、幅11.16、SD1.01、−90.2）は内部の局所極大と一致する。本スクリプトでは、t1 の1秒分解能に由来する σ ≥ 1/√12 s を下限として、この局所解を採用した。どちらの解でも、一様型が Gumbel と対数正規より対数尤度で上回る、という結論は変わらない。
- 対数正規：照合値 −92.5 は3母数（loc も推定）の −92.48 と一致する。loc=0 に固定すると −92.59 になる。
